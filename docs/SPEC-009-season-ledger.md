The Season Ledger answers the two questions that come up every time the stack grows: **what can Boyd merge, in what order, right now**, and **which physicals must be re-run first**. A physical verdict is only worth something for the exact head SHA it checked; a later push (even screenshots) moves the head. So the ledger keys every verdict by PR number **and** head SHA (the pstack orchestrate playbook's "verification ledger keyed by PR + head SHA"), folds in what is known about how each head moved since its last VERIFIED (a recorded *drift*: the files that changed), and lays the open draft PRs out in merge order with one status each: `fresh`, `docs-only`, `stale`, `failed` or `unverified`. It ships as one pure core function shared by `dd ledger`, `GET /api/ledger` and a ledger view at `#/ledger` (with a `Ledger` link on the Big Board), usable at 390, 430 and 1280, light and dark, every control and link at least 44×44 at every width.

## GOAL
Add the Season Ledger. ### Ledger entries (binding; one JSON object per line of `data/ledger.jsonl`)
```ts
type Verdict = "VERIFIED" | "NOT_VERIFIED" | "INCONCLUSIVE";
type LedgerLevel = "live-ui-verified" | "unit-test-verified" | "type-check-only" | "verifier-blocked" | "verifier-failed";
interface PrEntry      { kind: "pr"; at: string; repo: string; number: number; title: string; headRef: string; headSha: string; baseRef: string; draft: boolean; state: "open" | "closed"; merged: boolean }
interface VerdictEntry { kind: "verdict"; at: string; repo: string; number: number; headSha: string; verdict: Verdict; ledger: LedgerLevel; certainty: 1 | 2 | 3 | 4 | 5; agentId?: string; note?: string }
interface DriftEntry   { kind: "drift"; at: string; repo: string; number: number; fromSha: string; toSha: string; files: string[] }
type LedgerEntry = PrEntry | VerdictEntry | DriftEntry;
```
`parseLedgerEntry(value, allowlist)` runs these checks **in this order**; the first failure is the reason (exact strings):
1. not a plain object → `not an object`; 2. `kind` not one of the three → `bad kind`; 3. any key not in that kind's field list (the key orders above) → `unknown field`; 4. `at` not `YYYY-MM-DDTHH:MM:SS(.sss)Z` or not a real date → `bad at`; 5. `repo` not `BoydVC/<name>` (`[A-Za-z0-9._-]+`), containing `kpd` (any case), or not in the allowlist → `bad repo`; 6. `number` not an integer 1…999999 → `bad number`;
7. **pr**: `title` non-blank string ≤ 300 code points → `bad title`; `headRef` / `baseRef` match `^(?![/-])(?!.*\.\.)[A-Za-z0-9._/-]{1,200}$` → `bad headRef` / `bad baseRef` (checked headRef, headSha, baseRef in that order); `headSha` 40 lowercase hex → `bad headSha`; `draft` boolean → `bad draft`; `state` `open`/`closed` → `bad state`; `merged` boolean, and `true` only when closed → `bad merged`.
8. **verdict**: `headSha` (40 hex) → `bad headSha`; `verdict` → `bad verdict`; `ledger` → `bad ledger`; `certainty` integer 1–5 → `bad certainty`; `agentId`, when present, `bc-` + a full lowercase UUID → `bad agentId`; `note`, when present, a string ≤ 300 code points → `bad note`.
9. **drift**: `fromSha` (40 hex) → `bad fromSha`; `toSha` (40 hex, ≠ `fromSha`) → `bad toSha`; `files` an array of 1–500 non-empty strings ≤ 300 code points, none starting with `/`, no `..` segment, no U+0000–U+001F/U+007F–U+009F → `bad files`.

A valid entry is returned with exactly its kind's keys in the order above (optional keys only when present). `ledgerLine(entry)` = `JSON.stringify(entry)` of that canonical object. `readLedger(text, allowlist)` splits on `\n`, strips one trailing `\r`, skips blank lines silently, records `not JSON` for unparsable lines and the check reason otherwise, numbering lines from 1: `{ entries: {line, entry}[], skipped: {line, reason}[] }`. `prEntriesFromPulls(pulls, at, allowlist)` maps each GitHub pull (`base.repo.full_name`, `number`, `title`, `head.ref`, `head.sha`, `base.ref`, `draft`, `state`, `merged = typeof merged_at === "string"`) to a `pr` entry at `at`, validates each with `parseLedgerEntry` (first failure → `pull <index>: <reason>`; a non-array → `not a pulls array`), and returns them sorted by number.

| Admit picks | Sort logs by pick id. Skip with the four gardener reasons in that order (events sorted by `seq`, then `ts`, `type`, `key`). Ignore picks whose `pick_created.source` is in `EXCLUDED_SOURCES` (`ignored.selftest`), then picks whose trimmed `pick_created.target` ≠ `repo` (`ignored.otherTarget`). For each admitted pick: claim = `reduce(…).graft.prNumber` when the graft is recorded and the number is a positive integer; verdicts = `reduce(…).verdicts` in order, keeping only well-formed ones (positive integer `prNumber`, 40-hex `headSha`, known `verdict` and `ledger`, `certainty` 1–5); each malformed one counts in `ignored.badVerdicts`. |
| Ledger entries | Only entries whose `repo` equals `repo` count; the rest add to `ignored.otherRepo`. |
| Verdict sequence per PR | Pick verdicts first (pick-id order, then their order in the pick), then ledger verdicts sorted by (`at`, line). `source` is `pick` or `ledger`; `agentId` is the entry's or null. |
| Observation | The latest `pr` entry per number by (`at`, line) wins. `state: open` → a row; closed and `merged` → `merged`; closed and not merged → `closed`. Verdicts for numbers never observed show nowhere. |
| Status (per open row) | Let *atHead* = the last verdict whose `headSha` is the row's `headSha`. If there is one: `fresh` when it is VERIFIED, else `failed`. Otherwise, let *lastVerified* = the last VERIFIED verdict (any SHA): if there is one, take the latest drift (by `at`, line) with `fromSha` = its SHA and `toSha` = the head; `docs-only` when that drift exists and every file starts with `docs/`, else `stale`. With no VERIFIED at all: `unverified`. `verifiedSha` = the head when fresh, else lastVerified's SHA, else null. `drift` = `{files, docsOnly}` of the matched drift, else null. `verdicts` = sequence length; `last` = the last verdict of the sequence (or null). `picks` = sorted ids of admitted picks claiming this number. |
| Why | `fresh` → `verified at <sha7> (certainty <c>)`; `failed` → `<VERDICT> at <sha7>`; `docs-only` → `verified at <v7>; head <h7> changed docs only (<n> file(s))`; `stale` → `verified at <v7>; head moved to <h7>` plus ` (<n> file(s), not docs-only)` when a drift matched; `unverified` → `last <VERDICT> at <s7>; head moved to <h7>` when any verdict exists, else `no verdict`. `file` is singular at exactly 1. |
| Stack | A row's `parent` = the lowest-numbered other open row whose `headRef` equals its `baseRef` (else null). Depth = 1 + the deepest child (cycle-safe). The stack starts at the deepest root (parent null; ties → lowest number) and repeatedly steps to the deepest child (ties → lowest number) until there is none. `position` = 1-based index in the stack, null off it. `offStack` = every other open row, ascending. `rows` = stack rows in order, then off-stack rows. |
| Merge call | `mergeSafeThrough` = the last PR of the longest stack prefix whose statuses are all `fresh`/`docs-only` (null if the first is not). `rerun` = stack rows with status `stale`, `failed` or `unverified`, in stack order. `counts` count stack rows only. `notDraft` = open rows with `draft: false`, ascending. |
| Summary | `No open PRs` when `open` is 0; otherwise parts joined with ` · `: `<open> open PR(s)`; `stack #a→#b (<len>)` (or `stack #a (1)`, or `no stack`); `merge-safe through #n` or `merge-safe through none`; `re-run #x, #y` or `re-run none`; the non-zero counts in status order as `<n> <status>` joined with `, `; `<k> off stack` when any; `NOT DRAFT #x, #y` when any. |
| Text | `ledgerText`: the summary, then one line per row `<position or -> #<n> <status> · <why> · <title>`, then `skipped line <n>: <reason>` and `skipped log <id>: <reason>`. Every U+0000–U+001F, U+007F–U+009F, U+2028 and U+2029 in a title or id becomes U+FFFD. |

### CLI and API (binding)
| Surface | Contract |
|---|---|
| `dd ledger` | Reads `loadLogs(dataDir)`, `readLedgerFile(dataDir, targets)`, `targets[0]`; prints `ledgerText`; exit 0. `--json` prints `ledgerJson(…)`. |

| `dd ledger record <file.jsonl\|->` | Reads the file (or stdin for `-`) with `readLedger`. **Any** skipped line → print `line <n>: <reason>` for each to stderr, write nothing, exit 1. Otherwise appends the canonical lines and prints `ledger +<added> (<already> already recorded)`. |
| append rule | Under `withLock(<dataDir>/ledger.lock)`: create `dataDir` if needed, read the existing file's lines (trailing `\r` stripped), skip every new line already present (or repeated earlier in the same batch) and count it in `already`, append the rest each followed by `\n`.
